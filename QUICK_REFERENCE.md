## 🎮 What We're Building

**ClueLux** = Wordle + AI Hints + Multi-Length Words + Static Hosting

### Core Innovation
- **AI Hints**: 5 progressive clues generated by GPT-4
- **Static Build**: Zero runtime API calls, infinite scale
- **Daily Updates**: Automated rebuild every midnight
- **Multi-Length**: Support 5, 6, 7, 8-letter words

---

## 🏗️ Architecture at a Glance

```
Daily Build (Midnight UTC)
    ↓
Select Word → Generate Hints → Bundle Data → Build Site → Deploy
    ↓
src/data/today.json (embedded in static build)
    ↓
User Plays Game (100% offline, zero API calls)
```

## 💡 Hint Generation (OpenAI)

### Prompt Template
```
Generate exactly 5 progressive hints for "{WORD}":
1. Broad thematic clue
2. Contextual usage
3. Conceptual association  
4. Structural clue (rhyme, category)
5. Letter-based clue (first/last letter)

Format: JSON array of 5 strings
Keep under 15 words each
Use emojis sparingly
Never reveal exact word
```

### Fallback (if API fails)
- Template-based hints using word metadata
- First/last letter
- Vowel/consonant count
- Category hints

## 📊 Game Logic

### Max Attempts by Length
| Length | Attempts |
|--------|----------|
| 5      | 6        |
| 6      | 7        |
| 7      | 8        |
| 8      | 9        |

### Hint Unlock Schedule
| Length | Unlocks After Attempts |
|--------|------------------------|
| 5      | 1, 2, 3, 4, 5          |
| 6      | 1, 2, 3, 4, 5          |
| 7      | 1, 2, 3, 4, 6          |
| 8      | 1, 2, 4, 6, 8          |

### Tile States
- `correct` - Right letter, right position (green)
- `present` - Right letter, wrong position (yellow)
- `absent` - Letter not in word (gray)

## 🎨 Key Components

### GameEngine
- `evaluateGuess()` - Compare guess to answer
- `isWinningGuess()` - Check if all correct
- `updateKeyboardState()` - Track letter states
- `getMaxAttempts()` - Based on word length

### HintManager
- `getHintUnlockSchedule()` - When to unlock hints
- `getAvailableHintsCount()` - How many unlocked
- `shouldRevealHint()` - Check if hint should unlock
- `updateHintStates()` - Update hint availability

### ValidationEngine
- `isValidWord()` - Check against word list
- `normalizeWord()` - Sanitize input
- `checkWordLength()` - Validate length

## 🐛 Debugging Tips

### Build Fails
1. Check OpenAI API key is set
2. Verify master_words.json exists
3. Check internet connection
4. Review GitHub Actions logs

### Game Not Loading
1. Verify today.json exists
2. Check date format
3. Validate JSON structure
4. Clear browser cache

### Hints Not Working
1. Check hint unlock schedule
2. Verify wrong guess count
3. Inspect hint state in devtools
4. Test hint reveal function
